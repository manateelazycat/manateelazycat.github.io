我的第十八个 Omarchy 插件

我自己给 Omarchy 写了很多插件，同时我又在多台电脑上用 Omarchy 开发软件， 在我提交插件到 Omarchy 审核的时候， 我迫切的需要在多台电脑上同步我安装的 Omarchy 插件

所以， Omarchy Git Sync 就完成了，它的机制是追踪每个插件的 Git 地址，而不是追踪 Omarchy 商店，这样就可以立即在多台电脑上同步 Omarchy 插件啦

源代码按照 GPL 3.0 发布， Enjoy！
