#### 仁慈的独裁者

世界上伟大的作品，其实都是由仁慈的独裁者创造的。

就拿大家最认同的 Linux 开源社区的发展来说，离不开两个人。第一个是创造 GNU 工具链的 Richard Stallman，另外一个人就是创造 Linux 内核的 Linus。

斯托曼老人家当年在 Unix 大型机横行的时代，创作了一系列的底层编译工具链。GCC、GDB、Emacs 和一系列 GNU 的底层软件，都是这个老人家一手创建的。在当时 Unix 横行、面对基本上所有人的不理解时，他一意孤行，打下了良好的编译工具链基础，才有了今天 Linux 上层的枝繁叶茂。

Linus 大神当年在芬兰的大学待了整整 8 年，就为了创作一个跟 Minix 截然不同的 Linux 系统，独自一人搞定了 POSIX 接口和完整的 x86 内核。

如果没有当时这两个人坚定的意志、超强的能力和仁慈的独裁，我相信大家今天不会享受到 Linux 开源社区的繁荣，也不可能有安卓和服务器的生态。

很多人说，Linux 社区的成功更源于开源社区全世界黑客的巨大贡献，当然，这是无可否认的。但是你们要知道，最关键的是，这两位老人家做了前面的 1，才有后面社区的 0。工程化的东西，可以靠人多力量大来解决；但是开创性的理念，只能靠最开始的那一个人去做决策。

#### Linux 桌面缺少什么

Linux 桌面本身已经有了非常好的基础，但是为什么发展不起来？就是因为缺少一个足够好的桌面系统。

而一个足够好的桌面系统，不光是内核要足够强大、技术要多么先进。一个桌面系统最重要的就是交互体验和取舍，简而言之，就是让你装上去就用得舒心。

Linux 桌面发展这么多年，面对普通人的需求时，就被拉扯得很奇怪。很多人说，你为什么这里不像 Windows，那里不像 Windows；这里不像 Mac，那里不像 Mac？最后在各种抄袭中迷失了自我。

其实我觉得完全没必要。因为 Linux 的主要人群就是工程师，他们装 Linux 的目的就是探索开源库，然后创造很多新的玩法。

所以 Linux 桌面就应该聚焦到这些工程师身上，做一个快捷键导向、简洁高效的开发环境。而 DHH 本身就是兼具超强工程能力和优秀审美的天才，他可以把很多纷繁复杂的需求转化为简洁高效的默认设置。

#### 期待 DHH 的 Linux 桌面

所以我非常看好 DHH 在 Linux 桌面上的创作，因为他本身就是最懂工程师的产品设计师。而 Linux 社区，有超强技术的人一大把，但是有审美的产品设计师寥寥无几。

期待 DHH 更多设计，做出无与伦比的 Linux 桌面。
